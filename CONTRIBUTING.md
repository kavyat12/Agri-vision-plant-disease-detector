# Contributing

1. Fork + branch (`feat/...`, `fix/...`, `docs/...`).
2. Backend: `pytest -q` and `ruff check app tests` from `backend/`.
3. Frontend: `npm run build` from `frontend/` (lint when configured).
4. Never substitute synthetic diagnosis, chat, or weather data for an unavailable service.
5. Update docs for user-facing changes. Small, focused PRs win.

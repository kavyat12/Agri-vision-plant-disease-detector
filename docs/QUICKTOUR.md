# 5-minute local workflow

1. Configure an AI provider key and start the backend/frontend.
2. Register an account from **My farm** and sign in.
3. Add, edit, and delete a crop record; verify the record remains after reload.
4. Upload a real leaf photo to request an AI visual assessment.
5. Review the disease library, local diagnosis history, and agricultural chat.

Without a provider key, image assessment and chat return configuration errors;
they do not produce sample results.

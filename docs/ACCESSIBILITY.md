# Accessibility statement

- Keyboard: Tab order logical, Enter to analyze, Esc to clear, visible focus rings.
- Screen reader: `aria-live` for progress/toasts, labeled tabs, alt text on previews.
- Motion: `prefers-reduced-motion` disables float/shimmer/slide.
- Contrast: severity badges tested light/dark; touch targets >=44px.
- Known gap: canvas sample art is decorative (`aria-hidden`) with text labels.
